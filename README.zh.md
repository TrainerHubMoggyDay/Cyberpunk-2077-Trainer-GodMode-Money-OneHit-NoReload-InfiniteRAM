## 使用方法

1. 通过绿色按钮下载 ZIP
2. 解压
3. 启动 **Cyberpunk 2077**
4. 启动训练器
5. 等待 `Cyberpunk2077.exe`
6. 分类：佣兵 / 战斗 / 义体 / 经济 / 世界
7. `Num` = 开关 · `Ctrl+Shift+Home` = 全部关闭
8. 界面语言：**EN** / **RU**

| 按键 | 作用 |
|---------|----------|
| `Num …` | 开关 |
| `Ctrl + Shift + Home` | 全部关闭 |
