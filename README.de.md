## Nutzung

1. ZIP über den grünen Button laden
2. Archiv entpacken
3. **Cyberpunk 2077** starten
4. Trainer starten
5. Auf `Cyberpunk2077.exe` warten
6. Kategorien: Mercenary / Combat / Cybernetics / Economy / World

|---------|----------|
| `Num …` | Ein / Aus |
| `Ctrl + Shift + Home` | Master Off |
