## Как пользоваться

1. Скачай ZIP по зелёной кнопке
2. Распакуй архив
3. Запусти **Cyberpunk 2077**

5. Дождись `Cyberpunk2077.exe`
6. Категории: Наёмник / Бой / Кибернетика / Экономика / Мир
7. `Num` — вкл/выкл · `Ctrl+Shift+Home` — выключить всё
